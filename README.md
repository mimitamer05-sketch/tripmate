# Tripmate 🌍

Tripmate is a modern, feature-rich travel booking application designed to provide a seamless experience for planning and booking your next adventure. Built with React and Vite, it offers a fast, responsive, and visually stunning interface.

## ✨ Features

- **Flight Search & Booking**: Find and book flights with ease.
- **Hotel Discovery**: Explore a wide range of hotels with detailed information and zoomable images.
- **Activity Planning**: Discover and book local activities and attractions.
- **Transport Options**: Get precise directions and GPS coordinates for your trips.
- **Booking Management**: Keep track of all your bookings in one place.
- **Multi-language Support**: Fully translated into German.
- **Modern UI**: Sleek design with light theme, white cards, and blue accents.

## 🚀 Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Vanilla CSS
- **Icons**: Lucide React
- **Maps**: Leaflet, React Leaflet
- **Utilities**: date-fns, html2canvas, jspdf

## 🛠️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/tripmate.git
   ```
2. Navigate to the project directory:
   ```bash
   cd tripmate
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## 📖 How to Use

1. **Onboarding**: Enter the number of adults and children to start your search.
2. **Search**: Browse through flights, hotels, and activities.
3. **Booking**: Click the "Book" button to see details and confirm your selection.
4. **My Bookings**: View your confirmed bookings and transport details.
